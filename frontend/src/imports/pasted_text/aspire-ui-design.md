Design a modern, clean, and professional web application UI for ASPIRE: Analytics Systems for Predictive Insights and Refined Educational Outcomes, an educational analytics platform.

🧩 1. GENERAL DESIGN STYLE

Light-themed UI (NOT dark-heavy)

Main background: white (#FFFFFF)

Accents: red gradients and subtle soft shadows

Clean, minimal, professional layout

Smooth animations (fade-in, scroll reveal)

Avoid overly dark backgrounds

🎨 Color Palette:

Primary Red: #bc1313

Deep Red: #890E0E

Accent Red Gradient: #bc1313 → #430202

Background: #FFFFFF (main)

Secondary Background: #f8f8f8 (sections)

Text: #1a1a1a (dark gray/black)

🔤 Typography:

Headings: Instrument Serif (with red accents/italics)

Body: modern sans-serif (clean and readable)

Hero text: bold, elegant (not too heavy)

✨ Visual Style:

Soft gradients instead of dark glows

Minimal shadows

Clean dividers (thin lines or subtle shimmer)

Rounded corners (medium radius)
